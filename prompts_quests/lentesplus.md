### 1. El Problema (Contexto y Dolor)

- **Cliente/Contexto:** Lentesplus.com el cual es un e-commerce de lentes de contacto y gafas
- **El dolor principal:** El sitio web ya contaba con una pagina pero esta ya estaba demasiado antigua y con muy poco UX, entonces entramos a rediseñar la pagina teniendo en cuenta tambien un rebranding que le hicieron a la marca, reformando el UX para una mejor experiencia de compra y asi motivar mas a los usuarios a usar el sitio web
- **Situación anterior:** Tenian un sitio web bastante antiguo y con un UX muy pobre, generando que los usuarios no usen el sitio web y pierdan muchas posibilidades de compra

### 2. Proceso y Reto Técnico

- **Decisiones clave UX:** Se entrevistaron usuarios para entender el problema del sitio web y por que la alta tasa de rechazo y rebote, generando asi un diseño y volviendo a entrevistar a nuevos usuarios para asi hacer pruebas y nuevas iteraciones de los diferentes flujos, en especial flujo de compra desde seleccionar el producto hasta pagar y terminar la compra (esto teniendo en cuenta que la venta de lentes de contacto es mas complicada por las diferentes dioptrias y formulas de los mismos)
- **Reto UI/Frontend:** generar los nuevos flujos para la seleccion de diptrias y nuevos flujos de compra para asi tener un flujo mas agragable visualmente para el usuario y asi motivarlos a conocer los diferentes productos y comprarlos

### 3. Impacto y Resultados

- **Métricas/Resultados:** Se mejoraron las metricas de compra desde el sitio web en un 50%, ademas de mejorar la tasa de rebote y el tiempo en la pagina hasta 2min aprox y en flujos de compra se insentivo a tener un flujo de maximo 1min
- **Resultado tangible:** se creo un sitio web moderno y con flujos mas faciles para los usuarios para que entiendam mejor la compra de lentes de contacto
