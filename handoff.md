## 1. Resumen del Proyecto

Portafolio web interactivo híbrido (UX/UI + Frontend) con temática **Dark RPG (Premium & Accesible)**. Objetivo: convertir a reclutadores y clientes mediante casos de estudio detallados, en un entorno interactivo, accesible (WCAG) y de alto rendimiento.

Metáforas: proyectos = **Quests**, "Acerca de mí" = **Character Sheet**, tecnologías = **Items/Inventario**, experiencia laboral = **Skill Tree**.

Estado actual: **estructura inicial creada** (scaffold funcional, sin contenido real todavía). El proyecto se organiza según el "Sistema de Agentes Full-Stack" (`sistema_agentes.md`), donde cada dominio de código pertenece a un agente especializado.

## 3. Arquitectura y Stack Tecnológico

- **Core:** Next.js 16 (App Router) + React 19 + TypeScript. Se eligió Next.js sobre Vite porque el portafolio necesita SEO fuerte (debe posicionar en Google y ser indexable para reclutadores).
- **Estilos:** Tailwind CSS v4 (config vía `@theme inline` en `src/app/globals.css`, sin `tailwind.config.js` clásico).
- **Animaciones:** Framer Motion (instalado, presets aún por construir en `src/lib/hefesto/motion.ts` o similar).
- **Estado:** Zustand (instalado, stores aún por crear en `src/state/minerva`).
- **Validación de datos:** Zod (esquemas en `src/lib/demeter/schemas`).
- **Utilidades:** `clsx` + `tailwind-merge` (helper `cn()` en `src/lib/utils.ts`), `lucide-react` para iconografía.
- **Tipografía:** Cinzel (display/serif épica) + Inter (sans, contenido) vía `next/font/google`.

## 6. Errores ocurridos y su solución

- **`create-next-app` rechazó el nombre "DEVIUS"** por restricciones de npm (no permite mayúsculas en el nombre del paquete). Solución: se generó el scaffold en un directorio temporal con nombre válido (`devius-portfolio`) y se movió el contenido a la raíz del proyecto, preservando `sistema_agentes.md`.
- **`npm run build` falló con `EPERM: operation not permitted, unlink .next/export-detail.json`** al limpiar la carpeta `.next` en el entorno remoto. Causa: el shell remoto no tenía permiso de borrado en la carpeta montada por defecto. Solución: se solicitó permiso de borrado explícito para la carpeta del proyecto; tras habilitarlo, `rm -rf .next && npm run build` completó sin errores.
